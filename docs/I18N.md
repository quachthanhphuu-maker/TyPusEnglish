# TyPusEnglish — Internationalization & Localization (i18n)

Quy định cấu trúc đa ngôn ngữ và quy chuẩn chuỗi giao diện cho TyPusEnglish sử dụng **`next-intl`**.

Dựa trên: [PRD.md](PRD.md) (Yêu cầu hỗ trợ Tiếng Việt & Tiếng Anh ngay từ P0).

---

## 1. Ngôn ngữ hỗ trợ & Định dạng mặc định

* **Ngôn ngữ hỗ trợ:**
  * `vi` (Tiếng Việt) — Ngôn ngữ mặc định.
  * `en` (English) — Tiếng Anh.
* **Định tuyến (Routing):**
  * Sử dụng Middleware của `next-intl` để nhận diện locale từ cookie/URL: `/[locale]/...`
  * Tự động chuyển hướng root `/` sang `/${defaultLocale}/...`.

---

## 2. Cấu trúc thư mục Translation

Toàn bộ chuỗi giao diện được lưu trữ tập trung tại thư mục `messages/`:

```text
messages/
├── vi.json       # Toàn bộ bản dịch Tiếng Việt
└── en.json       # Toàn bộ bản dịch Tiếng Anh
```

---

## 3. Quy chuẩn Namespace & Khóa bản dịch (Key Conventions)

Để tránh xung đột và tiết kiệm token khi nạp ngữ cảnh dịch thuật, cấu trúc JSON được phân tầng theo domain tính năng:

| Namespace | Mục đích sử dụng |
| :--- | :--- |
| `common` | Các nút hành động chung (`save`, `cancel`, `delete`, `edit`, `back`, `confirm`), trạng thái nạp (`loading`, `submitting`). |
| `auth` | Đăng nhập, gửi magic link, hết hạn phiên, quyền truy cập. |
| `classes` | Tạo lớp, quản lý hồ sơ học sinh, danh sách lớp, tạo mã mời. |
| `lessons` | Lịch dạy, điểm danh (`present`, `absent`, `late`, `excused`), ghi chú buổi học. |
| `assessments`| Bài tập, ngân hàng câu hỏi, chấm điểm, hạn nộp, trạng thái nộp bài. |
| `tuition` | Học phí, hóa đơn, trạng thái thanh toán (`unpaid`, `partially_paid`, `paid`, `overdue`), ghi nhận giao dịch. |
| `reports` | Báo cáo phụ huynh định kỳ, xuất bản báo cáo, nhận xét giáo viên. |
| `self_study` | Flashcard, bộ từ vựng, mục tiêu ngày, chuỗi ngày học (streaks). |

### Ví dụ cấu trúc `messages/vi.json`:
```json
{
  "common": {
    "actions": {
      "save": "Lưu",
      "cancel": "Hủy",
      "create": "Tạo mới",
      "delete": "Xóa"
    },
    "states": {
      "loading": "Đang tải...",
      "empty": "Không có dữ liệu",
      "error": "Đã có lỗi xảy ra. Vui lòng thử lại."
    }
  },
  "lessons": {
    "attendance": {
      "present": "Có mặt",
      "absent": "Vắng",
      "late": "Đi muộn",
      "excused": "Có phép"
    }
  },
  "tuition": {
    "status": {
      "unpaid": "Chưa thanh toán",
      "partially_paid": "Thanh toán một phần",
      "paid": "Đã thanh toán",
      "overdue": "Quá hạn"
    }
  }
}
```

Authentication text stays in the `auth` namespace in both locale files.
Keep safe error-code messages for invalid email, throttling, invalid or
expired magic links, invitation failures, expired sessions, unauthenticated
requests, forbidden workspaces, and generic internal errors. Never display
raw Auth.js/provider/database errors.

## 4. Định dạng Ngày tháng, Giờ và Tiền tệ

* **Tiền tệ (Currency):**
  * Theo [DATABASE.md](DATABASE.md#p0-data-model), số tiền lưu trữ dưới dạng số nguyên (minor units).
  * VND có số mũ `0`: định dạng theo chuẩn Việt Nam (ví dụ: `150.000 ₫`).
  * USD có số mũ `2`: định dạng chuẩn quốc tế (ví dụ: `$15.00`).
* **Thời gian (Date & Time):**
  * Database lưu trữ chuẩn UTC.
  * Hiển thị phía Client: Luôn định dạng theo IANA Timezone của lớp học hoặc của người học (mặc định: `Asia/Ho_Chi_Minh` cho thị trường Việt Nam).
  * Sử dụng formatters chuẩn từ `useFormatter()` của `next-intl`.

## 5. Quy tắc bắt buộc cho AI Agent khi lập trình Frontend

1. **Tuyệt đối không hardcode text tiếng Việt hoặc tiếng Anh trong JSX/TSX.**
   * *Sai:* `<button>Lưu thay đổi</button>`
   * *Đúng:* `const t = useTranslations('common.actions'); return <Button>{t('save')}</Button>;`
2. Khi thêm mới một thành phần UI hoặc trường form, **bắt buộc cập nhật đồng thời cả 2 file `messages/vi.json` và `messages/en.json`**.
3. **Pluralization & Tham số động:** Luôn dùng ICU message syntax thay vì cộng chuỗi thủ công:
   * *Ví dụ:* `"studentCount": "{count, plural, =0 {Chưa có học sinh} other {# học sinh}}"`
